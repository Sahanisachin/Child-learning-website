# 🌟 Child Learning Website

A fun, interactive and animated learning website designed especially for **UKG students**.

The website helps young children practice basic **Mathematics and English** through colorful games, animations, rewards and simple interactive activities.

---

## 🎯 About The Project

**Child Learning Website** is an educational practice platform created for UKG-level students.

Instead of traditional worksheets, the website provides a **game-like learning experience** where children can answer questions, earn stars, maintain streaks and unlock rewards.

The main goal is to make learning:

- 🎮 Fun
- 🎨 Interactive
- 🧠 Educational
- ⭐ Rewarding
- 👶 Easy for young children

---

## 📚 Learning Activities

### 🔢 Mathematics

The website includes practice for:

- 🔤 Number Spelling — 1 to 50
- ✖️ Table of 2
- ✖️ Table of 3
- ✖️ Table of 4
- ✖️ Table of 5
- ⬅️ Before Numbers
- ➡️ After Numbers
- 🔢 Between Numbers
- `>` Greater Than
- `<` Less Than
- `=` Equal To
- ➕ Addition
- ➖ Subtraction
- ⬆️ Ascending Order
- ⬇️ Descending Order
- 📏 Long and Short
- ✏️ Fill in the Blanks
- 🔢 Smallest and Biggest Number
- 🥇 Ordinal Numbers

### 🔤 English

- 🔀 Unscramble the Word
- 🧩 Simple UKG-level vocabulary
- 🖼️ Picture-based word learning
